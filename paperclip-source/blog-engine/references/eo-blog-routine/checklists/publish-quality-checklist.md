# Publish Quality Checklist

Use this before any new article or finishable draft is published.

## Candidate Gate

- [ ] Course Formula Gate is complete.
- [ ] Relevant scales in `scales-and-rubrics.md` are applied.
- [ ] `skill-routing-map.md` was followed and the skill trace is started.
- [ ] `scorecards-and-traces.md` artifacts exist or are being maintained.
- [ ] `stage-task-map.md` was followed; stage packets or equivalent fresh-agent stage outputs are recorded.
- [ ] Article Promise is declared.
- [ ] Business Value is not 0.
- [ ] Parent topic and search intent are clear.
- [ ] Keyword Vulnerability Gate is complete with named weak ranking URLs and our counter-asset.
- [ ] Link reality is winnable or has a promotion/linkable-asset plan.
- [ ] Cannibalization check is complete.
- [ ] Free-seeker/no-filter risk is discounted and handled.
- [ ] The candidate has a real uniqueness asset.

## Research And Outline

- [ ] Ahrefs metrics and SERP overview are present.
- [ ] Top-ranking pages and formats are summarized.
- [ ] BEAT SPEC exists.
- [ ] Must-cover topics are mapped to H2s.
- [ ] H2s are MECE and open with BLUFs.
- [ ] Product proof and visual slots are planned.
- [ ] Feature Fit Matrix from `product-proof-and-brand-mentions.md` exists when Pleasur.AI will be mentioned.
- [ ] Internal links are planned.
- [ ] The uniqueness asset has a specific section.
- [ ] Contagious STEPPS check is complete if this is a linkable/promotable article.
- [ ] Author/style packet exists with selected author, profile/slug/id, and 3-5 examples or a
  justified house-style fallback.

## Draft

- [ ] First screen answers the query.
- [ ] The article has a clear POV.
- [ ] The article does not read like generic SEO prose.
- [ ] Author Fit score is at least 3 and no author/byline hard gate is failing.
- [ ] The uniqueness asset is present in the body.
- [ ] At least five headline angles were brainstormed before choosing the H1.
- [ ] Pleasur.AI mentions are natural and proof-led.
- [ ] Pleasur.AI mentions map reader job -> live feature -> proof -> link -> visual.
- [ ] `/pricing` is used only in cost/plan/coin sections and repeated pricing links are justified.
- [ ] Live features only. No roadmap-as-live claims.
- [ ] Adult/NSFW framing is accurate and not sterile legal filler.
- [ ] No internal tooling/vendor names appear in reader-facing prose.

## Claims

- [ ] Statistics are cited.
- [ ] Product claims are verified live.
- [ ] Pricing/date claims are current.
- [ ] Legal, privacy, age, consent, and safety claims are sourced or removed.
- [ ] Competitor claims are sourced or softened.
- [ ] No `[link]`, `[CITATION NEEDED]`, `TODO`, or prompt markers remain.

## Visuals, Header, Cover

- [ ] `visual-header-cover-checklist.md` passes.
- [ ] `visual-system.md` passes.
- [ ] Visual Proof score is at least 3 or a route-specific exception is documented.
- [ ] Cover image is present and approved.
- [ ] Visual count and role mix fit article length.
- [ ] At least one product proof visual exists for product-led posts.
- [ ] Visual manifest is non-empty and not table-only.
- [ ] No `[VISUAL]` placeholders remain on the live page.

## Preview And Publish

- [ ] Preview renders cleanly.
- [ ] H1/title/meta/slug are correct.
- [ ] Cover image and OG image are correct.
- [ ] Author id/slug is present in the publish payload.
- [ ] Rendered byline and author profile/link are present when the route supports them.
- [ ] Tables and components render correctly.
- [ ] Links work.
- [ ] CTA path works.
- [ ] Live page returns HTTP 200.
- [ ] Live H1 matches expected title.
- [ ] No placeholder, `[GAIN]`, hidden prompt marker, or broken asset leaks.

## Done Comment

- [ ] URL or no-publish disposition.
- [ ] Course Formula Gate summary.
- [ ] Killed candidates.
- [ ] Article Promise.
- [ ] Uniqueness asset and proof it shipped.
- [ ] Visual/header/cover checklist result.
- [ ] Author/byline result and author packet path.
- [ ] Scorecard and skill trace paths.
- [ ] Claims/link/render verification.
- [ ] Book-skill result if Contagious or Oversubscribed was used.
- [ ] Artifact paths.
- [ ] Follow-up issue IDs.
