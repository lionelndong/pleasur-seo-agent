# EO Blog Routine Reference Pack

`execution-contract.md` is the single authoritative operating contract for the active PLE
new-content routine. The remaining files provide domain detail. If stage numbers, data access,
cadence, failure behavior, or publish authority differ, the execution contract wins. Routine
descriptions should stay short and reference this pack instead of copying the entire prompt set.

## Core Rule

The blog engine is not a volume machine. It is a customer-acquisition system.

Ryan Law gives the workflow architecture. The Ahrefs course gives the strategy formula. Pleasur.AI
must provide the unique proof, product angle, and point of view.

Two common failures are hard failures:

- An empty, table-only, or generic visual set.
- A brand mention that links pricing by default instead of showing the relevant feature/use case.

The new-content routine and weekly existing-content review are separate, equally important loops.
The review is not a second publishing pipeline: it selects at most one focused child, and the
measurement routine closes the feedback loop after cooldown.
