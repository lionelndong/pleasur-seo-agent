# Improvement And Relaunch Checklist

Use this for existing posts. This lane repairs or relaunches; it does not create new articles.

## Selection

- [ ] `portfolio-improvement-system.md` was read.
- [ ] Customer/revenue, GSC, Ahrefs portfolio, internal-integrity, and external-link evidence were
  kept distinct; unavailable evidence lowered confidence.
- [ ] Ahrefs browser/export evidence records report, target, filter/window, observation time, and
  Paperclip work-product URL.
- [ ] Open issues/manifests and the measurement cooldown registry were checked.
- [ ] At least three candidate fixes were considered when available.
- [ ] Every candidate has a priority class; the within-class priority formula is computed.
- [ ] Relevant scales in `scales-and-rubrics.md` are applied.
- [ ] `skill-routing-map.md` was followed and the skill trace is started.
- [ ] `scorecards-and-traces.md` artifacts exist or are being maintained.
- [ ] The selected fix has the highest surviving customer impact.
- [ ] Business Value is not 0, unless the work is a technical/live-rendering repair.
- [ ] The current failure mode is named.

## Fix Promise

- [ ] Current failure mode is explicit.
- [ ] Full traffic/customer potential is stated.
- [ ] Business Value and free-seeker discount are stated.
- [ ] Estimated links needed or fix effort is stated.
- [ ] Relaunch uniqueness asset is declared.
- [ ] Authority source is declared.
- [ ] Visual repair plan is declared.
- [ ] Conversion path is declared.
- [ ] Contagious or Oversubscribed lens is declared if the relaunch needs links, promotion, or a
  fresh public hook.
- [ ] Author/byline failure mode is checked and an author-style packet exists when the relaunch
  changes author-facing copy or fixes a missing/wrong author.

## Allowed Fix Types

- [ ] Relaunch thin, outdated, visually weak, or decaying content.
- [ ] Repair broken visuals, tables, metadata, links, or live rendering.
- [ ] Improve product proof, intent match, CTA, internal links, or information gain.
- [ ] Propose cannibalization merge/redirect without executing destructive changes.
- [ ] Create one precise follow-up issue when another owner is needed.
- [ ] Broken-backlink work is sourced from Ahrefs Broken backlinks/Best by links, not a full-site
  LLM crawl, and is treated as link equity rather than GSC demand.

## Relaunch Quality

- [ ] The relaunch uniqueness asset appears in the revised article body.
- [ ] Visual/header/cover checklist passes.
- [ ] The edit materially improves at least one of: customer path, intent match, rankings,
  information gain, product proof, visual usefulness, internal-link flow, claim accuracy, or live rendering.
- [ ] It is not a cosmetic-only edit.
- [ ] No unsupported claims were introduced.
- [ ] No roadmap-as-live claims were introduced.
- [ ] Author Fit score is at least 3 when copy was rewritten.
- [ ] No author/byline hard gate is failing.
- [ ] No destructive action was taken without approval.

## Verification

- [ ] Preview or live page was checked.
- [ ] HTTP status is recorded.
- [ ] H1/title/meta are correct.
- [ ] Cover and OG image are correct.
- [ ] Rendered byline and author profile/link are present when the route supports them.
- [ ] Visuals/tables/components render.
- [ ] Links and CTA path work.
- [ ] No placeholder, `[GAIN]`, hidden prompt marker, or broken asset leaks.

## Done Comment

- [ ] Selected fix URL/action.
- [ ] Selection matrix summary.
- [ ] Deferred/killed candidates.
- [ ] Fix Promise.
- [ ] Relaunch uniqueness asset and whether it shipped.
- [ ] Visual repair plan and final visual role mix.
- [ ] Author/byline result when relevant.
- [ ] Scorecard and skill trace paths.
- [ ] Before/after summary.
- [ ] Verification result.
- [ ] Artifact paths.
- [ ] Book-skill result if Contagious or Oversubscribed was used.
- [ ] Follow-up issue IDs.
- [ ] Run disposition, measurement-registry row, and 14-21 day due date when anything ships.
