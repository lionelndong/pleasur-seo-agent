# Original Paperclip SEO source package

This directory preserves the source materials recovered from the Paperclip SEO/blog-engine setup so they can be inspected, referenced, and ported into Buzz.

## Contents

- `agent/` — the SEO agent’s `AGENTS.md`, `SOUL.md`, `TOOLS.md`, `HEARTBEAT.md`, `SCORECARD.md`, memory policy, and role context.
- `blog-engine/.claude/skills/` — the full skill library available to the blog engine, including each original `SKILL.md`, references, scripts, and templates.
- `blog-engine/references/` — the routine’s source map, execution contract, prompt map, stage-task map, scorecards, quality rules, visual system, product-proof rules, and portfolio-improvement system.
- `blog-engine/templates/` and `blog-engine/docs/` — supporting templates and documented integration notes.
- `blog-engine/PIPELINE.md`, `README.md`, and `brand-config.md` — the original top-level operating material.

## Reading order

Start with `agent/AGENTS.md`, then `blog-engine/PIPELINE.md`, then `blog-engine/references/eo-blog-routine/execution-contract.md`. The execution contract is the authoritative routine for the active four-run weekly publishing lane.

## Important context

This is a source archive, not a promise that every historical file remains current. Some historical skills mention retired providers or older cadence and publishing behavior. For current behavior, the execution contract takes precedence. No credentials, private keys, live tokens, browser sessions, VPS configuration, logs, or runtime artifacts are included.
