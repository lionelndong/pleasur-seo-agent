# SEO — PARA Memory Index

All paths are relative to this agent directory.

- `life/projects/` — active work with a clear goal or deadline
- `life/areas/` — ongoing responsibilities, entities, people, and companies
- `life/resources/` — durable reference material and topics
- `life/archives/` — inactive material moved from the other categories
- `memory/YYYY-MM-DD.md` — raw dated chronology
- `MEMORY.md` — compact tacit operating patterns

## Retrieval order

1. Read the relevant entity's `summary.md`.
2. Read `items.yaml` only when atomic facts are needed.
3. Search dated notes for chronology.
4. Prefer active facts; preserve superseded facts for provenance.

- `areas/role/` — stable context for the SEO role
